Method

How We Run This Check

The same method we run for Namebeam, we run for every customer. No customer gets a softer version.

Buyer-intent queries

We define real questions a buyer would actually type or ask an AI assistant, not keywords chosen to make the numbers look good.

Live engine runs

We run each query live, on the actual engine, and log the raw answer as it came back, not a cached or simulated version.

Site crawl

We check robots.txt (the file that tells crawlers what they may access), the sitemap (the file listing a site's pages for search engines), and llms.txt (a newer file some sites publish for AI crawlers specifically).

Index check

We run a site: search on Google to see how many pages of the property are actually inside Google's index, not just published on the web.

Domain Rating pull

We pull Domain Rating from Ahrefs, a 0 to 100 estimate of how much a site's backlink profile would help it compete in search.

Dated, disconfirming-first

Every result is dated the day we pulled it. We look for reasons a result might be wrong or unflattering before we look for reasons it is right.

If the method would embarrass a customer, we run it on ourselves first.
